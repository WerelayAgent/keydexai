Your data

Privacy

What we keep, what we don’t, and where requests go.

Last updated November 9, 2026

TermsPrivacyRisks
TermsPrivacyRisks

On this page

What we store

The wallet you sign in with and the IP address of its first sign-in. API keys as salted hashes, with name, spend and dates. Your counted token balance. Per call: time, key, model or tool, tokens, cost and status. Unfinished sign-in requests.

What we don’t store

Prompts, replies and private keys.

Trial keys

For trial keys we keep your IP address, to limit them to 3 per visitor in 24 hours and to count the free daily allowance. The key stays in your browser tab until you close it or it expires.

Cookies and analytics

One cookie, kf_session, keeps you signed in for 30 days. It is HttpOnly. There is no analytics, no ad cookies and no tracking.

Token balance

Once the token launches, we read your wallet’s token balance at each model call and index the token’s public transfers on Solana. We keep the counted balance with that day’s allowance.

Server logs

Our server logs each request’s IP address as the server sees it, with the path and time. A path can include tool inputs such as a wallet address. API keys sent in a URL are removed before the log is written.

How long we keep data

We keep call records and IP addresses to run Keydex AI and limit trial keys and new wallets. Once a day we delete call records, trial keys with their IP addresses, allowance records and daily trial totals older than 90 days. After 90 days we also erase the IP address a wallet first signed in from; the wallet address and its account records stay until we delete them. Server logs are kept by our hosting provider under its terms.

Onchain data

Trades, funding and token purchases are public onchain, like any transaction.

Where requests go

Model requests pass through a model routing service to the provider of the model you pick, and each handles them under its own policies. Trade, funding and token purchase requests, with the wallet addresses in them, go to LI.FI and Relay. Wallet balances are read from Solana nodes.

Where data is stored

The server, database and logs run on a cloud hosting provider.

Your choices

Revoke any key you created in the app, and calls with it stop. Sign out to end your session in this browser. A trial key can’t be revoked: closing the tab removes it from this browser, and it expires within 24 hours.

Questions or data deletion requests: message keydexai on X or write to support@keydex.ai.
